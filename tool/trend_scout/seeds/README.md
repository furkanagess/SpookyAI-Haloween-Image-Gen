# Seeds

One file per season (`<season-id>.txt`). Paste concepts you noticed on
platforms that have no public API for developers (TikTok, Pinterest,
Instagram). Format, one per line:

```
concept text | optional note | optional source URL
```

Seeds are trusted (they skip the keyword filter) and score high, so they
always reach the concept stage. Keep them short and visual; the robot and the
reviewer do the rest.
